# Tarea3_2_Dinamicas

Proyecto académico en C# dedicado a **estructuras de datos dinámicas**.

## Contenido

El código incluye nodos, listas doblemente enlazadas, pilas y colas dinámicas. También contiene una cola circular estática y una interfaz gráfica para explorar y visualizar las estructuras.

## Requisitos

- Visual Studio con soporte para C# y Windows Forms.
- .NET compatible con `Tarea3_2_Dinamicas.csproj`.

## Ejecución

Abre `Tarea3_2_Dinamicas.sln` en Visual Studio y ejecuta el proyecto.

## Propósito

Practicar la implementación y comparación de estructuras de datos dinámicas y estáticas.
